# BOSS 岗位采集器

一个供个人求职使用的 Chrome 扩展：在 BOSS 直聘岗位详情页点击扩展，核对岗位字段后保存。岗位可保存在 Chrome 本地，也可以配置 Notion 后写入自己的岗位数据库。

> 当前通过“加载已解压的扩展程序”安装，尚未发布到 Chrome 网上应用店。BOSS 直聘页面结构调整时，自动识别可能需要更新；保存前请核对岗位信息。

## 功能

- 点击时采集当前 BOSS 直聘岗位，不在后台自动搜索。
- 展示并允许编辑岗位名称、公司、地点、薪资、招聘链接和描述。
- 保存到当前 Chrome 的扩展本地存储，并按岗位链接去重。
- 查看已采集岗位并导出 CSV。
- 配置 Notion API Token 和数据库 ID 后，可将岗位写入 Notion，同时保留本地副本。

## 安装

1. 从 GitHub 下载 ZIP 并解压，或使用 Git 克隆本仓库。
2. 在 Chrome 地址栏打开 `chrome://extensions`。
3. 打开右上角“开发者模式”。
4. 点击“加载已解压的扩展程序”，选择解压后的 `boss-notion-capture` 文件夹（里面应直接看到 `manifest.json`）。
5. 在 BOSS 直聘打开一个岗位详情页，点击工具栏中的扩展图标开始采集。

更新版本时，下载/拉取新文件后回到 `chrome://extensions`，点击扩展卡片上的刷新按钮，并刷新 BOSS 页面。

## 使用

1. 打开 BOSS 直聘岗位详情页。
2. 点击扩展图标，检查并修正自动识别的字段，尤其是公司名称和原始招聘链接。
3. 不连接 Notion时，点击“保存岗位”即可保存到本机；通过“已采集岗位”查看及导出 CSV。
4. 配置 Notion 后，点击“保存岗位”会先尝试写入 Notion，成功后也会保留本地副本。

## 可选：连接自己的 Notion 数据库

每位使用者都需要使用自己的 Notion 凭据，不要共用仓库作者的 Token。

1. 在 Notion 开发者工具中创建自己的 API 连接/令牌。
2. 将目标岗位数据库授权给该连接，并确保它有新增页面的权限。
3. 打开扩展的“设置”，填入自己的 Token 和数据库 ID，保存。
4. 采集一个岗位验证是否写入成功。

数据库 ID 可从 Notion 数据库链接中取得。当前字段映射适配 `W1_AI岗位研究表`，其他数据库需要包含相应属性或调整映射代码。

## 数据与隐私

- 岗位数据默认保存在当前 Chrome 用户配置中的扩展本地存储；清除扩展数据或移除扩展可能导致本地记录丢失，请定期导出 CSV。
- 配置 Notion 后，岗位字段会通过 HTTPS 发送到 Notion API，并写入用户配置的数据库。
- Token 保存在 Chrome 扩展本地存储中，只应填写自己的 Token；不要提交到 GitHub、截图公开、粘贴到聊天或分享给他人。
- 扩展仅在用户打开弹窗并点击保存时发起 Notion 写入；不要把 Token 放入源代码、README、Issue 或 Pull Request。
- 安装前请先检查源代码和权限。扩展需要读取 BOSS 页面可见内容，并需要访问 Notion API 才能实现写入。

## 项目文件

- `manifest.json`：扩展清单及权限
- `content.js`：读取当前 BOSS 页面可见岗位信息
- `popup.html`、`popup.js`：采集字段编辑与保存
- `options.html`、`options.js`：Notion 配置
- `jobs.html`、`jobs.js`：本地岗位记录和 CSV 导出

## 已知限制

- BOSS 直聘页面 DOM 可能调整，字段识别可能遗漏或选错；保存前请核对。
- 公司名称和岗位描述以职位详情页为准，推荐职位等页面内容可能造成误识别。
- Notion 属性名称和类型需匹配当前字段映射；接口报错时先检查数据库授权、ID 和字段。
- 本项目尚未发布到 Chrome 网上应用店，也没有自动更新机制。
